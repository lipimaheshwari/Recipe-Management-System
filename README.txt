RECIPE BOOK - LOCAL WEBSITE

1. Install Python 3 if it is not already installed.
2. Open PowerShell or Command Prompt in this folder.
3. Install the required package:
   py -m pip install -r requirements.txt
4. Start the website:
   py app.py
5. Open this address in your browser:
   http://127.0.0.1:5000

The recipes are stored in recipes.txt. Use the search box to find recipes by name.
Use the Add a recipe form to add recipes. New recipes are saved to recipes.txt.

To stop the website, press Ctrl+C in the terminal.
